# 📊 Calculadora de Presupuestos en Python y Generador de PDF

## 📝 Descripción
Este proyecto es un cuaderno práctico desarrollado en **Google Colab** como parte de un ejercicio de aprendizaje en Python. Permite interactuar con el usuario para capturar variables clave de un proyecto (descripción, horas estimadas, valor por hora y plazo), realizar el cálculo automático del costo total y generar un reporte formal en formato **PDF**.

---

## 🛠️ Tecnologías y Librerías Utilizadas
* **Lenguaje:** Python 3
* **Entorno de Desarrollo:** Google Colab
* **Librerías:**
  * `fpdf`: Utilizada para la creación y formato del documento PDF de salida.

---

## ⚙️ Funcionalidades del Código
1. **Entrada de Datos:** Captura interactiva de información mediante `input()`.
2. **Cálculos Matemáticos:** Procesamiento aritmético y conversión de tipos de datos (`int()`) para determinar el presupuesto total.
3. **Generación de Reportes:** Creación dinámica de un archivo denominado `Presupuesto.pdf` con la información formateada.
